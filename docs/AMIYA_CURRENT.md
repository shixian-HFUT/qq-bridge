# 当前维护基线

2026-10-31 整理到已有 fork 的独立分支 `codex/amiya-production`，以 fork `main` 的 `8518258f177e20901f86023fbf16b50bbc5af434` 为父版本，保留现有公开历史。

当前数据流：QQ / SnowLuma OneBot → Node bridge → Pi SDK → 提供商；桥接同时通过回环 HTTP 访问 LivingMemory。DSH 后端与管理工具兼容代码仍在，但 Pi 聊天不要求启动 DSH。

| 目录 | 内容 |
| --- | --- |
| `src/`、`public/`、`plugins/` | 当前桥接、控制台及插件 |
| `runtime/pi/` | 独立的 Pi 1.3.0 入口及锁文件 |
| `roles/阿米娅.md` | 当前角色表达的脱敏版本 |
| `dsh/agent-presets/` | 聊天约束及预设；Pi 读取相应提示词 |
| `services/livingmemory/` | 侧车、固定版本上游引擎、完整管理页与测试 |
| `deploy/` | Linux host 网络部署模板 |
| `scripts/` | 通用工具及当前回归测试 |

桥接采集了线上 65 个 `src/` 文件和配套资源。各文件的生产与仓库哈希记录在 `production-source-manifest.json`，真实身份已替换为合成示例。另补入已验证的任务测试脚本；这类测试不一定曾部署到生产主机。

角色依据运行时 ownerQQ 识别博士，昵称、自称及转发不改变绑定。公开卡去除私人称呼。群聊和私聊使用同一关系设定；情绪回顾需要当前消息或授权记忆依据，不新增独立的永久记仇库。

示例配置保留当前 Pi 聊天模型/思考档位与上下文预算作为起点，账号及会话为空。动态唤醒、发送、语音和记忆参数应由部署者核对，仓库中的模板不是生产配置备份。

本次只发布源码分支，没有修改运行中的服务、人设、白名单或记忆。以后部署应记录 commit 与镜像，避免再把唯一实现留在被忽略的任务目录中。
